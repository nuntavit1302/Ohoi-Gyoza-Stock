☁️ เชื่อมต่อ Cloud — หลายคนใช้ข้อมูลเดียวกัน
📡 สถานะการเชื่อมต่อ
❌ ยังไม่เชื่อมต่อ

Firebase Realtime Database ช่วยให้:

• พนักงานหลายคนใช้ข้อมูลเดียวกันบนมือถือคนละเครื่อง

• ข้อมูลอัปเดตแบบ Realtime (ทันทีที่มีการเปลี่ยนแปลง)

• ไม่ต้องกลัวข้อมูลหายเพราะอยู่บน Cloud

1สร้าง Firebase Project (ฟรี)

ไปที่: console.firebase.google.com

ทำตามขั้นตอน:

1. สร้างโปรเจคใหม่ → ตั้งชื่อ "Ohoi-Kyoza"

2. ปิด Google Analytics (ไม่จำเป็น)

3. เลือกเมนู Build → Realtime Database

4. กด Create Database → เลือก Server ใกล้ไทย (Singapore)

5. เปิดโหมด Start in test mode (อนุญาตทุกคนอ่าน/เขียน)

6. กด Project Settings → General → คัดลอก Config

2ใส่ Firebase Config

วางโค้ด Config ที่ได้จาก Firebase ลงในช่องด้านล่าง:

3ซิงค์ข้อมูล

เลือกทิศทางซิงค์:

• อัปโหลด = ส่งข้อมูลจากมือถือนี้ขึ้น Cloud

• ดาวน์โหลด = ดึงข้อมูลจาก Cloud ลงมือถือนี้

• Auto Sync = เปิดให้ซิงค์อัตโนมัติทุกครั้งที่มีการเปลี่ยนแปลง

📋 บันทึกการซิงค์:
4แชร์ให้พนักงาน

พนักงานคนอื่นเพียงแค่:

1. เปิดไฟล์นี้ในมือถือตัวเอง

2. ใส่ Firebase Config เดียวกัน

3. กด ดาวน์โหลดจาก Cloud

✅ เสร็จ! ทุกคนใช้ข้อมูลเดียวกันแล้ว
